    명령어와 세부 개념

    main은 각 저장소의 기준본을 가리키는 브랜치입니다. story는 내 작업 공간의 브랜치입니다. HEAD는 현재 작업 중인 브랜치를 가리킵니다.

    스테이징은 다음 기록에 포함할 파일 내용을 보관하는 영역입니다. PR은 변경 검토와 병합을 요청하는 기능입니다.

    이 실습은 병합 커밋을 만듭니다. 기준본을 받아올 때는 로컬 main에 추가 변경이 없어 fast-forward로 갱신합니다.

    실습 방법 · 개념 참고
    나는 본문을 수정합니다. 지수는 제목을 수정합니다. 지수는 정해진 동작과 의견을 보여 주는 가상 인물입니다.
    각 컴퓨터에 있는 저장소를 로컬 저장소라고 합니다. GitHub 저장소는 기록을 공유하는 원격 저장소입니다. 기록을 공유해도 다른 컴퓨터의 저장소는 자동으로 바뀌지 않습니다.
    현재 안내는 다음에 누를 버튼 하나를 가리킵니다. 기록 버튼은 당시 파일 내용을 보여 줍니다. “이전 단계”와 “다시 앞으로”는 이미 방문한 단계를 보여 줍니다.
    이전 단계에서 새 동작을 하면 이후 진행 결과는 사라집니다. 보기만 하면 기존 결과는 유지됩니다. 페이지를 새로고침하면 실습이 초기화됩니다.
    “3D 기록 참고”는 기록의 연결 관계를 보여 줍니다. 이 화면은 지수의 검토가 완료됐다고 가정합니다. 실제 검토 과정은 “2D 협업 지도”에 있습니다.
    이 실습은 최신 수정 기록에 대한 지수의 승인이 있어야 합칠 수 있습니다. 실제 GitHub의 필수 검토 설정은 저장소마다 다릅니다. 원격 추적 브랜치와 접근 권한 설정은 생략했습니다.

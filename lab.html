    실습 방법 · 개념 참고
    나와 가상 동료 지수가 백설공주 이야기를 함께 씁니다. 나는 본문, 지수는 제목을 고칩니다. 각자 컴퓨터에서 기록한 뒤 GitHub에 공유하고, 서로의 변경을 확인해 합칩니다. 합친 결과는 각 컴퓨터에서 따로 받아와야 합니다.
    강조된 저장소의 버튼으로 진행하고, 기록을 누르면 당시 내용을 볼 수 있습니다. 이전 단계로 돌아가 다른 선택도 해볼 수 있습니다. 지수의 작업과 의견은 정해진 시나리오입니다. 이 실습은 실제 GitHub 저장소를 변경하지 않으며, 새로고침하면 처음부터 시작합니다.
    ‘기록 흐름 참고’에서는 3D로 기록의 관계를 살펴볼 수 있습니다. 이 실습의 병합 조건은 최신 수정에 대한 동료 승인입니다. 실제 GitHub의 필수 리뷰 설정은 저장소마다 다릅니다. 원격 추적 브랜치, 충돌 해결, 접근 권한 설정은 생략했습니다. Git의 브랜치 · GitHub flow · 원격 변경 가져오기

    함께 실습하는 방법 · 개념 참고
    혼자일 때는 가상 동료 지수와 연습합니다. 같은 방에서는 첫 참여자가 작성자가 되고, 다른 참여자가 ‘확인하는 동료 · 맡기’를 눌러 역할을 나눕니다. 나머지는 관찰할 수 있습니다. 작성자는 수정하고, 리뷰어는 요청과 승인을 보냅니다. 각자의 시점과 선택한 파일은 독립적입니다.
    3D의 강조된 동화책나 기록을 눌러 조작하거나 표시된 자리에 끌어놓으세요. 이름표 버튼은 같은 동작을 실행하는 키보드·터치 대안입니다. 다른 기록은 눌러서 내용을 볼 수 있습니다. 자유 배치 조정은 ‘기록 흐름 참고’ 화면에서 사용합니다. 이 실습의 병합 조건은 최신 수정에 대한 동료 승인입니다. 실제 GitHub의 필수 리뷰 설정은 저장소마다 다릅니다. 방 링크를 가진 사람은 누구나 참여할 수 있습니다. 이름과 실습 상태는 서버 메모리에만 보관됩니다.
    정적 GitHub Pages에서는 혼자 탐색할 수 있습니다. 여러 기기 실습은 npm start로 실행한 서버에 같은 네트워크에서 접속하세요. 외부 인터넷에서 접속하려면 이 서버를 별도로 호스팅해야 합니다.
    원격 추적 브랜치, 충돌 해결, 접근 권한 설정은 이 실습에서 생략했습니다. Git의 브랜치 · GitHub flow · 원격 변경 가져오기

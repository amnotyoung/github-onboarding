Stitch가 반환한 원문
## 🌲 한국어 초보자용 GitHub 3D 학습 교보재 UX 검토 및 개선 제안

제공해주신 비식별 화면 요약과 사용자 요구사항을 바탕으로 진행한 **구체적 UX 문제 4가지**와 **우선순위 개선안 4가지**, 그리고 이를 최소 변경으로 반영한 **데스크톱 시안** 결과입니다.

---

### 1. 구체적 UX 문제 분석 (4개)

1. **학습자 인지 과부하 및 선행 개념 주입 문제**
   - 초보자는 'git push', 'origin/main', 'staged' 등의 용어를 접하면 즉각적인 인지 장벽을 느낍니다. 용어가 먼저 노출되면 "조작 → 상태 변화 인지 → 개념 학습"의 자연스러운 멘탈 모델 형성이 방해받습니다.
2. **비가역성 공포(Fear of Irreversibility)와 탐색 단절**
   - 현재 단계 이전으로 돌아갈 방법이 없어, 실수했을 때의 복구 불안감이 발생합니다. 반대로 단순 탐색 기능을 제공할 때 이를 '실제 Git 기록을 삭제하거나 reset/revert하는 파괴적 행위'로 오해할 소지가 매우 큽니다.
3. **과거 분기 수정 시 상태 인과관계(Causality) 피드백 부족**
   - 과거 단계에서 파일 수정 선택지를 변경했을 때 이후의 리뷰·승인·커밋 히스토리가 재계산된다는 맥락을 시각적으로 인지하지 못하면, 학습자는 "왜 방금 승인된 리뷰가 사라졌는지" 혼란을 겪게 됩니다.
4. **다중 사용자 환경에서의 주도권 및 뷰 불일치 혼선**
   - 여러 명이 동시 접속했을 때 진행자의 화면 조작이 전체 화면을 일방적으로 덮어쓰거나, 반대로 개인의 시점 조작(3D 카메라 회전 등)과 공유 장면 동기화의 경계가 모호하면 협동 학습의 집중도가 떨어집니다.

---

### 2. 우선순위 개선안 (4개)

| 순위 | 구분 | 개선 방안 및 상세 설계 |
| :--- | :--- | :--- |
| **P1** | **채택 가능 제안** | **비파괴적 '장면 둘러보기' 미니 플레이어 배치**<br>3D 캔버스 하단 중앙에 눈에 잘 띄면서도 공간 조작을 방해하지 않는 플로팅 형태의 `[◀ 이전 단계] [현재 3단계 / 5단계] [다음 단계 ▶]` 바를 배치하고, 하단에 *"단순 미리보기 중이며 실제 커밋은 변경되지 않습니다"*라는 안심 문구를 상시 표기합니다. |
| **P2** | **채택 가능 제안** | **'감각적 조작 → 시각적 변화 → 개념 명명'의 3단계 계진형 피드백**<br>화면 초기에는 일상적 언어("앞의 문서를 뒤로 밀어올리기")만 제시하고, 동작 완료 직후 캔버스 하단에 "✅ 로컬 문서가 원격으로 전달됨"을 보여준 뒤에야 비로소 "💡 방금 배운 개념: git push" 배지가 열리도록 정보 순서를 정돈합니다. |
| **P3** | **채택 가능 제안** | **과거 분기 수정 시 '시간선 재계산' 안내 모달/경고 배너**<br>과거 시점으로 이동해 선택지(A/B)를 변경하려 할 때 *"이 시점 이후의 리뷰와 승인 기록이 다시 작성됩니다"*라는 명확한 분기 경고와 함께 `[이 단계부터 새로 시작]` 명시적 버튼을 제공합니다. |
| **P4** | **조건부 제안**<br>*(협동 세션 활성화 시)* | **진행자 공유 장면(Presenter Lock)과 자유 카메라 뷰의 이원화**<br>다수 참여 세션 시 진행자의 핵심 이벤트(푸시, 브랜치 병합 등)는 강제 동기화하되, 참여자가 3D 각도를 자유롭게 돌려볼 수 있는 로컬 관찰 모드와 진행자 화면 복귀 토글(`[진행자 시점 보기]`)을 분리 제공합니다. |

---

### 3. 반응형 대응 (390px 모바일 화면 배치 원칙)
- **수직 스택 전환**: 데스크톱의 전후 원근 3D 뷰를 모바일에서는 상하(상단: 팀 원격 저장소 / 하단: 내 폰/컴퓨터 로컬)의 직관적 수직 레이어 구조로 자연스럽게 전환합니다.
- **플로팅 컨트롤 컴팩트화**: 타임라인 플레이어를 하단 바 독(Dock) 형태로 고정하여 한 손 엄지 조작 영역에 배치하고, 보조 모달(용어 사전, 리뷰)은 바텀 시트(Bottom Sheet)로 전환합니다.

---

### 4. 생성된 데스크톱 시안 안내
- **화면명**: `코드숲 - 깃허브 3D 공간 탐험 학습관` (`코드숲 - 깃허브 3D 공간 탐험 학습관`)
- **주요 적용 사항**:
  - 부드러운 Sage 배경 + Forest 본문 + Lime 액션 포인트를 유지하면서 3D 인터랙션 영역을 최대화
  - 캔버스 하단 중앙에 안심 안내가 포함된 미니 타임라인 컨트롤 장착
  - 하단 결과 바에서 동작 완료 후 개념(`git push`)이 등장하는 시각적 위계 정돈
  - 하단 보조 툴바에 수정안 비교, 리뷰 피드백, 쉬운 용어 사전을 모달 트리거 형태로 깔끔하게 정돈

Stitch의 추가 제안(아직 실행하지 않음)
- 390px 모바일 세로형 레이아웃 시안도 함께 확인하기
- 과거 단계에서 선택지 수정 시 나타나는 재계산 확인 모달 설계하기
- 진행자 동기화 모드(팀 실습)의 화면 UI 디테일 확인하기

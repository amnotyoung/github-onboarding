지도 애니메이션 가림 수정 — 2026-10-18 (이전 버전)

2026-10-19의 고정 화면·로컬 충돌 해결 설계로 대체됨. 현재 검증은 compact-local-review.txt 참조.

문제
자동 변경 설명 팝업과 배경 흐림이 실제 지도 위 애니메이션을 가렸다.

현재 동작
- 자동 변경 설명 dialog와 ‘확인하고 계속’ 단계를 제거했다.
- 변화는 실제 기록, 브랜치, 기준본, PR에서 재생한다. 원래 기록은 유지하고 복사본만 이동한다.
- 변경 요약은 일반 본문에 유지한다. 추가 도식은 ‘변경 도식 보기’를 사용자가 펼친다.
- 다음 작업은 애니메이션이 끝나면 활성화된다. 별도의 읽기 확인은 없다.
- 출발점과 도착점이 한 화면에 들어오면 둘을 함께 보여 준다. 긴 모바일 경로는 이동하는 기록을 따라간다.
- 사용자가 스크롤하면 자동 추적을 멈춘다. 도식 펼치기·화면 크기 변경은 이동 효과를 정리하고 최종 상태를 보여 준다.
- 모션 감소 설정은 팝업 대체 없이 변경 위치만 표시한다.
- 본문 수정·기록 내용 창은 사용자가 명시적으로 눌렀을 때만 열린다. 저장 뒤에는 창이 닫힌 상태에서 지도 변화가 시작된다.

검증
- npm test: 모델, 상태 복원, 설명 의미, 정적 서버 7개 통과.
- 세 실습 전체: 팝업 없는 흐름, 초기 로컬 부재, 단일 수정안, 지수 역할, 통합 상태, 탐색 등을 포함해 브라우저 267개 확인 통과.
- 실제 모션: 복제·공유·병합·충돌이 지도에서 보임, 설명 본문 유지, 도식 펼치기, 재생/탭 전환 정리 등 19개 확인 통과.
- 긴 모바일 경로와 중단: 8개 확인 통과. 320×568에서 화면 스크롤이 1532→1357→1109→938px로 이동하는 동안 기록은 화면 y=267~301px에 계속 보임.
- 모션 감소·화면 크기 변경 후 이동 요소와 잠금이 남지 않음. 브라우저 오류 없음.

- 브랜치: 기준본이 가리키는 기록에서 작업 공간이 갈라지는 모습을 보여 준다.
- 기록: 저장한 파일 상태에서 새 기록이 나타나고 연결선이 이어진다.
- 공유: 원래 기록을 유지하며 복사본을 GitHub 작업 공간으로 보낸다. 공유는 기준본 변경으로 표현하지 않는다.
- 병합: 기존 기준본과 새 기준본을 교차 표시한다. 이슈·충돌 실습은 기준본 변경 다음에 남은 PR의 충돌 상태를 표시한다.
- 받아오기: GitHub 기준본을 지정한 컴퓨터로 복사한다. 다른 컴퓨터는 바뀌지 않는다.
- 이전·다음: 이전 요소는 사라지고 새 요소는 나타난다. 실제 Git 기록 삭제가 아닌 학습 상태 탐색이라고 명시한다.
- 변경 설명과 ‘변화 다시 보기’를 남긴다. 다시 재생은 상태를 변경하지 않는다.
- 다음 단계 조작은 전환 동안 잠근다. 끝나면 다음 행동을 안내한다. 화면 전환 시 재생을 취소하고 모든 버튼을 원래 상태로 돌린다.
- 모션 감소 설정에서는 이동을 생략하고 변경 위치와 설명을 표시한다.

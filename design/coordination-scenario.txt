이슈·브랜치·충돌 및 미병합 PR 실습 — 2026-10-19

- 이슈 #21/#22는 나에게 할당한다. 통합 탭의 #23만 민수에게 할당한다. 할당은 책임 표시이며 브랜치 생성이나 파일 잠금이 아니다.
- 내 로컬 main B에서 story와 happy 브랜치를 만든다. 서로 다른 PR #31/#32가 같은 파일의 같은 줄을 수정한다.
- 각 PR은 B 기준으로 병합 가능하다. #31이 먼저 병합되어 main이 M1이 되면 #32의 H와 충돌한다.
- 지수는 이 시점에 저장소를 복제한다. 최신 main M1과 공유된 PR 기록을 받는다.
- 지수는 로컬 happy H를 열고 main M1을 합쳐 본다. 충돌 문장을 수정하고 R을 기록한다. 부모는 H와 M1이다.
- R은 Push 전까지 지수의 로컬에만 있다. Push 후 같은 PR #32가 R로 갱신되고 충돌 표시가 사라진다.
- 지수는 최신 R을 다시 검토하고 M2로 병합한다. 나와 지수는 각자의 main에 병합 결과를 받아온다.
- 통합 탭의 민수는 proposal S로 PR #33을 만든다. 지수는 백설공주 이야기 범위에 맞지 않는 신데렐라 장면을 제외하고 PR을 닫는다.
- 검토 제외 의견과 PR 닫기는 별도 동작이다. 닫힌 PR의 S는 보존하며 main에는 들어가지 않는다. 연결된 이슈 #23은 열린 상태로 남는다.
- 여러 PR이 있다는 사실만으로 충돌하지 않는다. 같은 줄의 경쟁 변경을 합치는 경우를 보여 준다.

한국어·영어 실습 지원 — 2026-10-20

- 실습실 헤더에 한국어 / English 선택을 추가했다.
- 탭, 단계 안내, 동작 버튼, 기록·파일 내용, 이슈·PR 상세, 역할 설명, 접근성 이름, 모션 문구를 번역했다.
- 영어에서는 지수=Emma, 민수=Noah로 표시한다. 한국어에서는 지수·민수를 유지한다.
- 시뮬레이션 데이터·브랜치·기록 ID는 유지한다. 표시 계층에서 원문을 보관해 언어 왕복 시 내용이 변하지 않는다.
- 언어만 바꾸면 현재 진행, 기록, 이전/다음 이력이 유지된다. 애니메이션 중 변경은 해당 동작을 완료한 상태로 전환한다.
- URL lang=ko/en > 저장된 선택 > 한국어 기본값 순서로 결정한다. 브라우저 저장이 막혀 있어도 URL 지정은 동작한다.
- 이전 iPhone 초기화 수정을 유지했다. 영어 로딩·실패 안내를 제공하며 변경된 자산 URL에 버전을 붙였다.
- 기존 발표 슬라이드와 소개영상은 한국어 자료로 유지한다.

검증
- npm test: 12개 통과. 모든 시나리오의 영어 안내·파일 내용, 동적 문자열, 이름, 상태 불변성, URL 우선순위를 포함한다.
- WebKit에서 1280×720와 320×568, 세 모드 전체 진행(13+26+39개 동작)을 각각 검사했다.
- 영어 화면의 한글 잔여(한국어 선택 옵션 제외), aria-label, 파일 편집창, PR·이슈·기록·현재 파일 상세를 검사했다. 번역 누락 없음.
- 언어 왕복, 이전/다음 복원, 선택 언어 저장, 화면·파일 버튼 잘림, 문서 스크롤을 확인했다.
- WebKit 및 Chromium에서 실제 모션 중 전환, 영어 모션·편집, CSS 지연, 영어 오류와 재시도를 확인했다.

- PORT=4180 node server.mjs 실행 후 Playwright CLI run-code로 tests/browser-language.js 및 tests/browser-language-motion.js를 실행한다.

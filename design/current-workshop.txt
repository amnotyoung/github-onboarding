현재 교보재 설계 — 2026-10-19

1. 복제 전에는 GitHub에만 B 기록이 있다. B는 파일명이 아니라 기록 이름이다.
2. 본문과 재수정은 고정된 한 문장으로 진행한다. 불필요한 정답 선택은 없다.
3. 협업 기초 탭은 나와 지수의 PR 하나를 다룬다. 지수는 검토·승인·병합을 맡는다.
4. 이슈와 충돌 탭은 내가 만든 두 PR의 충돌을 다룬다. 지수는 필요할 때 저장소를 복제하고 로컬 happy에서 충돌을 해결한다.
5. 종합 실습 탭에는 민수가 참여한다. 내 PR은 수정·승인·병합으로 이어지고, 민수의 PR은 범위에 맞지 않아 병합 없이 닫힌다.
6. PR을 닫아도 기록 S나 proposal 브랜치는 삭제하지 않는다. main과 이슈 #23도 바뀌지 않는다.
7. 충돌 파일 저장 → 로컬 기록 R → Push → 같은 PR 갱신 → 재검토·병합을 분리한다. Push 전에는 GitHub의 happy가 H를 유지한다.
8. 자동 설명 팝업과 자동 스크롤은 없다. 지도, 각 사람의 로컬, PR 상태, 다음 행동이 같은 화면에 남는다.
9. 변경 요약은 하단에 남긴다. 전체 설명과 파일·기록·이슈·PR의 내용은 사용자가 눌러 연다.
10. 이전/앞으로는 학습 상태를 복원한다. 탭마다 진행 상태는 독립적이다. 새로고침하면 초기화한다.

현재 교보재 설계 — 2026-10-18

사용자 피드백 반영
1. 복제 이전에는 원격에만 B 기록이 있다. 로컬 컴퓨터에는 프로젝트 폴더, .git, 파일, 기록을 렌더하지 않는다.
2. 본문과 재수정은 각각 고정된 한 문장이다. 라디오 선택과 자유 입력은 없다.
3. 모든 PR의 작성자는 나, 검토·승인·병합 담당자는 지수다. 실제 프로젝트의 필수 인원 규칙으로 설명하지 않는다.
4. 기본, 이슈/충돌, 통합의 세 2D 탭을 제공한다. 통합은 하나의 저장소와 변경 이력을 유지한다.
5. 변경 설명은 사용자가 ‘확인하고 계속’을 누를 때까지 남는다. 모션 감소 설정에서도 동일하다.
6. 이슈에는 담당자 배지, PR에는 상태 색상, 충돌에는 같은 줄의 나란한 비교와 색상을 유지한 합친 결과가 있다.
7. 해결 문장 편집과 해결 기록 작성은 별도 단계다. 최신 해결 기록에 대한 지수의 승인이 필요하다.

초기 상태와 복제, 고정 수정안, 역할, 충돌, 통합 경로와 탐색 복원을 workshop-model.mjs의 테스트로 검증한다.
이전 디자인 검토 문서는 당시 버전의 이력이며, 현재 동작의 기준은 이 문서와 README다.

검증 결과
- 상태 모델과 정적 서버 테스트 5개 통과.
- 세 실습의 처음부터 끝까지, 고정 문장, 지수의 역할, 통합 이력과 탭·단계 복원: 브라우저 200개 확인 통과.
- 카드 유지·명시적 확인·재생·모션 감소·시각적 할당/충돌·320px 화면: 브라우저 15개 확인 통과.
- 실제 모션에서 3.2초 뒤에도 복제 설명 카드가 남아 있음. 해결 설명도 2.2초 뒤 유지됨.
- 브라우저 페이지 오류 없음. Three.js 요청 및 canvas 없음.
